# Do It — the planner that won't let you quit

One Expo (React Native + TypeScript + Expo Router) codebase for iOS, Android and
web. The web build is a home-screen web app (PWA) for iPhone.

```bash
npm install
npm run web         # dev server in the browser
npm run build:web   # static export to ./dist (what Vercel/Netlify deploy)
npm run typecheck
```

See **Deploying from your phone** below.
